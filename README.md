# Book24Cab - Outstation Cab Service Platform

A modern, high-converting outstation and intercity cab booking web application for North India travel corridors (Delhi NCR, Bareilly, Haridwar, Rishikesh, Nainital, Manali, Agra, Lucknow, Ayodhya, and more).

## Features
- **Interactive Cab Booking Engine**: One-Way, Round-Trip, and Airport Transfer support with live fare estimation.
- **Direct WhatsApp Booking Dispatch**: Instant booking and quotation forwarding directly to WhatsApp without requiring third-party APIs.
- **Interactive Corridor Showcase**: Ticket-style route cards with highway journey flow visualizer, destination purpose badges, and live Sedan/SUV vehicle fare toggling.
- **Fleet Showcase**: Specifications, passenger capacities, luggage allowances, and per-km tariffs for Sedan, SUV, Innova Crysta, and Tempo Traveller.
- **Confidential Operator Portal**: Hidden admin panel (`#owner-login`) with dispatch lead logs, 1-click WhatsApp/Call triggers, route tariff editor, and CSV export.
- **Modern Responsive Design**: Uber/Ola-inspired Deep Onyx Black and Electric Emerald Green color theme with mobile drawer navigation and high-resolution SVG favicon.

## Tech Stack
- **Frontend**: Semantic HTML5, Modular Vanilla JavaScript (ES6+), Modern Vanilla CSS3.
- **Local Dev Server**: Node.js `http-server` on port `8080`.

## Quick Start
```bash
npm install
npm run dev
```
Visit `http://localhost:8080/` in your browser.
